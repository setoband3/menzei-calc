# 免税控除計算（インボイス経過措置）

免税事業者からの仕入れについて、インボイス経過措置の控除額を計算するスマホ向け電卓です。

- 仕入れた日で控除割合（80% → 70% → 50% → 30%）を自動判定します
- 税込／税抜、10%／軽減税率8%に対応しています
- 仕入れリストに追加して、控除できる額の合計も見られます

## 開き方

スマートフォンのブラウザで次のURLを開きます。

https://setoband3.github.io/menzei-calc/

iPhoneでは、Safariの共有メニューから「ホーム画面に追加」すると、アプリのように開けます。

計算結果は目安です。正式な申告は税理士・税務署にご確認ください。
